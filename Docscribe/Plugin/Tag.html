Overview

A single YARD-style tag returned by a TagPlugin.

Examples:

Simple tag

Tag.new(name: 'since', text: '1.3.0')
# => # @since 1.3.0

Tag with types

Tag.new(name: 'raise', types: ['ArgumentError'], text: 'if name is nil')
# => # @raise [ArgumentError] if name is nil
